## Adjustment and survivorship gate

The Finhay source snapshot has 3,001,106 cleaned price rows but **0** adjusted total-return closes. Its corporate-action snapshot has 11,027 events. The earliest cash-dividend event is 2022; stock-dividend/bonus/rights records start in 2023. Of 3,182 cash dividends, 724 lack an amount; 15/220 bonus-share and 42/530 stock-dividend records lack complete ratios; 23/160 rights offerings lack a right-to-share ratio and subscription price. The [Finhay event reference](https://developers.fhsc.com.vn/api-reference/tin-tuc-su-kien/su-kien-quyen-cua-stock) specifies event fields but not complete historical coverage or a total-return adjustment formula. The [historical-price reference](https://developers.fhsc.com.vn/api-reference/bang-gia-thi-truong/lich-su-gia-co-phieu) defines OHLCV bars and does not promise adjusted values. Therefore the action snapshot cannot safely backfill earlier actions or prove a complete total-return series.

The raw `raw-2014-2026/` files were checked across all ticker bars: none contains `adClose`, `adjustedClose`, or `adjusted_close`; their price fields are only `date,open,high,low,close,volume`. Finhay documents `GET /market/stocks/{symbol}/events` with optional date filters and event-specific terms, but gives no historical lookback/completeness guarantee and publishes no adjustment formula. Its OHLCV endpoint documents no adjusted-close field. Events use the Tier-1 `X-FH-APIKEY` header; a variable named `FHSC_API_SECRET` alone is not that documented API-key credential. That exact variable was absent from this runtime, no repository dotenv file was present, and a no-credential read-only probe returned HTTP 401. No new events were collected. The earlier Finhay snapshot remains limited to events in 2021–2026, not the full P1 price history.

The requested VNDirect Finfo host `finfo-api.vndirect.com.vn` resolves to a private `10.x` address from this sandbox and its requests time out. A separate host alias, `api-finfo.vndirect.com.vn`, resolves publicly and returned HTTP 200 for real VCB/FPT queries across recent and 2014 dates. These responses include `adClose`; for example VCB 2014-12-31 has raw `close=31.9` and `adClose=9.298`. VNDirect's [official description of adjusted close](https://www.vndirect.com.vn/thong-bao-ve-thay-doi-cua-website-vndirect/) says it adjusts historical prices for cash dividends, stock splits, bonus shares and preferential offerings, and explains that it is intended to include those return effects. However, the current API field's exact implementation/version, units, full 2014–2026 P1 coverage, and project license/terms still need confirmation. A GitHub Actions audit now fetches the exact required P1 endpoint prices. Its first run failed because the collector read a gzip session file as plain CSV; this was fixed and covered by a test. The rerun is in progress (`43690604095`); no prices or labels are yet reported from that job.

Additional provider-documentation review did not close this gap. FiinGroup's [HOSE Stock V2](https://datafeed.fiingroup.vn/api-datafeed-en/api-trading/stock/stock/hose-stock-v2) and [adjusted-price-ratio](https://datafeed.fiingroup.vn/api-datafeed-en/api-trading/stock/stock/adjusted-price-ratio) pages expose adjusted-price fields, but do not define the adjustment formula, cash-dividend treatment, direction of `RateAdjusted`, or historical coverage; the English and Vietnamese descriptions of `IsReverse` also disagree. This is a candidate to request and independently validate, not a verified total-return source. The [SSI corporate-actions endpoint](https://developers.ssi.com.vn/en/docs/api-reference/data-corporateActions) requires an authorized bearer scope and limits each request to five days; the page notes that some announced events can have empty ex-right dates or ratios, and does not establish archive completeness or adjusted-price methodology. Neither source was accessed for bulk market data in this audit. FiinGroup's commercial terms/data license and actual historical coverage also remain unverified.

The current HOSE/HNX listing rules are Decision [22/QĐ-HĐTV](https://thuvienphapluat.vn/van-ban/Chung-khoan/Quyet-dinh-22-QD-HDTV-2026-Quy-che-Niem-yet-va-giao-dich-chung-khoan-niem-yet-699119.aspx); the corresponding UPCoM rule is Decision [23/QĐ-HĐTV](https://luatvietnam.vn/chung-khoan/quyet-dinh-23-qd-hdtv-2026-ban-hanh-quy-che-dang-ky-va-quan-ly-giao-dich-chung-khoan-chua-niem-yet-435227-d1.html). They are leads for exchange reference-price treatment, not a complete event ledger or a documented vendor total-return series. Do not label a locally derived reference-price adjustment from this incomplete snapshot as verified total return.

The requested HF dataset `datnkhptit/vn-stock-ohlcv` is gated (`auto`, license `other`); the existing HF token was rejected with `GatedRepoError` HTTP 403 in workflow `43685488389`. No gate terms or profile sharing were accepted. Its public metadata lists 144 P1 ticker directory overlaps but only 87 P1 silver-file paths. A separate ungated public repo `Trung2710/vn-stock-ohlcv` has 55 symbols and 50 P1 ticker overlaps (3.78%); a temporary local schema check found 140,815 bars with `close_adj`, but no license is declared and the exchange column is null for every row. It is not a complete or verified replacement.

The Drive API itself still returns HTTP 403 because the OAuth caller lacks `serviceusage.services.use` on quota project `764086051850`; this no longer prevents reading the four supplied files from their HF mirror. For the gated HF dataset, an HF account holder must explicitly accept its access terms before the configured token can read it. Google quota guidance: [Troubleshoot ADC](https://docs.cloud.google.com/docs/authentication/troubleshoot-adc).

## Current disposition

The real OHLCV source fixes the calendar/coverage problem, but step (1) is **not passed**: adjusted total-return labels, complete corporate-action history, and point-in-time listing/sector evidence remain unverified. Do not relabel raw close or vendor “adjusted price” as total return without verified semantics. Use the observed calendar and preserve/censor exact missing quotes; keep labels provisional until action adjustments and their coverage are validated. The training code rejects v1 labels, and no train/smoke-train was run.

The earlier Finhay-only weekday calendar is superseded and must not be used. All evidence is summarized in [[file:docs/p2a-progress-24.md]].
