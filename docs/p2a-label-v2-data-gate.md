## Adjustment and survivorship gate

The Finhay source snapshot has 3,001,106 cleaned price rows but **0** adjusted total-return closes. Its corporate-action snapshot has 11,027 events. The earliest cash-dividend event is 2022; stock-dividend/bonus/rights records start in 2023. Of 3,182 cash dividends, 724 lack an amount; 15/220 bonus-share and 42/530 stock-dividend records lack complete ratios; 23/160 rights offerings lack a right-to-share ratio and subscription price. The [Finhay event reference](https://developers.fhsc.com.vn/api-reference/tin-tuc-su-kien/su-kien-quyen-cua-stock) specifies event fields but not complete historical coverage or a total-return adjustment formula. The [historical-price reference](https://developers.fhsc.com.vn/api-reference/bang-gia-thi-truong/lich-su-gia-co-phieu) defines OHLCV bars and does not promise adjusted values. Therefore the action snapshot cannot safely backfill earlier actions or prove a complete total-return series.

The raw `raw-2014-2026/` files contain only OHLCV, as previously verified. The Finhay events API was not used for labels because its event snapshot is incomplete and its docs give no total-return formula.

The public alias `api-finfo.vndirect.com.vn` returned HTTP 200 for recent and 2014 VCB/FPT samples and exposes `adClose`. VNDirect's [official description of adjusted close](https://www.vndirect.com.vn/thong-bao-ve-thay-doi-cua-website-vndirect/) says it adjusts for cash dividends, splits, bonus shares and preferential offers and includes those return effects. Liaison explicitly authorized internal training use of the API field. Return ratios cancel the provider price-unit scale. No fetch errors occurred. At exact required endpoint dates, 16,196 Finfo rows reported an exchange floor different from the P1 partition; those prices were excluded, leaving any affected exact endpoints uncensored only if both start and target prices matched the P1 exchange/calendar. All unavailable adjusted endpoints were censored. Aggregate counts are in `docs/p2a-finfo-adclose-coverage.json`.

VNDirect's website terms on redistribution were raised with Liaison. Liaison's decision for this project is internal model-training use only, with no public raw-price dataset release. The successful run uploaded only private label candidates and aggregate metadata; the raw endpoint CSV was not included. No Finfo price values were committed to GitHub or HF.

Additional provider-documentation review did not close this gap. FiinGroup's [HOSE Stock V2](https://datafeed.fiingroup.vn/api-datafeed-en/api-trading/stock/stock/hose-stock-v2) and [adjusted-price-ratio](https://datafeed.fiingroup.vn/api-datafeed-en/api-trading/stock/stock/adjusted-price-ratio) pages expose adjusted-price fields, but do not define the adjustment formula, cash-dividend treatment, direction of `RateAdjusted`, or historical coverage; the English and Vietnamese descriptions of `IsReverse` also disagree. This is a candidate to request and independently validate, not a verified total-return source. The [SSI corporate-actions endpoint](https://developers.ssi.com.vn/en/docs/api-reference/data-corporateActions) requires an authorized bearer scope and limits each request to five days; the page notes that some announced events can have empty ex-right dates or ratios, and does not establish archive completeness or adjusted-price methodology. Neither source was accessed for bulk market data in this audit. FiinGroup's commercial terms/data license and actual historical coverage also remain unverified.

The current HOSE/HNX listing rules are Decision [22/QĐ-HĐTV](https://thuvienphapluat.vn/van-ban/Chung-khoan/Quyet-dinh-22-QD-HDTV-2026-Quy-che-Niem-yet-va-giao-dich-chung-khoan-niem-yet-699119.aspx); the corresponding UPCoM rule is Decision [23/QĐ-HĐTV](https://luatvietnam.vn/chung-khoan/quyet-dinh-23-qd-hdtv-2026-ban-hanh-quy-che-dang-ky-va-quan-ly-giao-dich-chung-khoan-chua-niem-yet-435227-d1.html). They are leads for exchange reference-price treatment, not a complete event ledger. Liaison authorized use of Finfo adjusted closes for internal training and prohibited publishing the raw adjusted-price dataset. The Actions job will retain only aggregate coverage metadata and v2-labeled P1 files; the endpoint-price CSV will not be included in the artifact.

The requested HF dataset `datnkhptit/vn-stock-ohlcv` is gated (`auto`, license `other`); the existing HF token was rejected with `GatedRepoError` HTTP 403 in workflow `43685488389`. No gate terms or profile sharing were accepted. Its public metadata lists 144 P1 ticker directory overlaps but only 87 P1 silver-file paths. A separate ungated public repo `Trung2710/vn-stock-ohlcv` has 55 symbols and 50 P1 ticker overlaps (3.78%); a temporary local schema check found 140,815 bars with `close_adj`, but no license is declared and the exchange column is null for every row. It is not a complete or verified replacement.

The Drive API itself still returns HTTP 403 because the OAuth caller lacks `serviceusage.services.use` on quota project `764086051850`; this no longer prevents reading the four supplied files from their HF mirror. For the gated HF dataset, an HF account holder must explicitly accept its access terms before the configured token can read it. Google quota guidance: [Troubleshoot ADC](https://docs.cloud.google.com/docs/authentication/troubleshoot-adc).
